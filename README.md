# Featureflip Homebrew tap

Homebrew casks for [Featureflip](https://featureflip.io) tools.

```sh
brew install canopy-labs/tap/featureflip
```

The casks in `Casks/` are updated automatically when a release is published. Report problems in the tool's own repository, such as [canopy-labs/featureflip-cli](https://github.com/canopy-labs/featureflip-cli).
